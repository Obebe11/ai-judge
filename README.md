# 🏛 ИИ Судья — честный суд для срачей в Telegram

> Плагин для [exteraGram](https://plugins.exteragram.app) который **беспристрастно** решает кто прав в сраче. Судья не знает кто есть кто — судит только по аргументам, фактам и логике.

## ⚖️ Принцип абсолютной честности

Обычный суд в чате — это друзья, админы, "у кого громче голос" и "кто старше в чате". ИИ Судья спроектирован чтобы исключить это полностью.

### 1. Слепой суд (Blind Court) — неотключаем

LLM **никогда** не видит реальные ники, аватары, статусы, роли.

```
Реально:   @admin_petya (админ, 5 лет в чате) vs @newbie_vasya (новичок)
Судья видит: Сторона A vs Сторона B
```

- До отправки в LLM плагин анонимизирует всех участников: `user_id → Сторона A/B/C` в порядке появления (`_anonymize:586`).
- Подмена происходит **до** вызова LLM — даже если модель захочет быть необъективной, у неё нет данных для фаворитизма.
- Только **после** вердикта плагин подставляет реальные имена обратно через макросы `Сторона A → Петя` для показа людям.
- **Отключить анонимизацию нельзя** — переключатель убран в v1.0.2. В настройках теперь только плашка `🔒 Анонимизация включена всегда`. Это гарантия честности.

> **Гарантия:** факап типа "админ всегда прав" технически невозможен — судья не знает кто админ.

### 2. Судят факты, а не эмоции

Системный промпт (`DEFAULT_PROMPT:23`) жёстко требует:

- Оценивать **аргументы и логику**, а не личности
- Искать логические ошибки (`ad hominem`, `соломенное чучело`, `апелляция к авторитету`)
- Проверять фактические утверждения и требовать источники
- Вернуть `confidence 0-100` — если данных мало, вердикт = `Недостаточно данных`, а не гадание

Судья не может сказать "Сторона A права потому что она звучала увереннее". Он обязан разобрать по пунктам.

### 3. Макросы — честная подмена

```
LLM вернул:  winner = "Сторона B"
Плагин показал: 🏆 Победитель: Сторона B (@vasya)
```

Макросы (`{winner}`, `{count}`) подставляются **после** решения. Это исключает ситуацию где модель подстраивает ответ под конкретный ник.

В коде: `_format_verdict:699` делает `deanon()` только для отображения, исходный `verdict_json` остаётся слепым и логируется.

### 4. Доказательства > мнение

Вердикт обязан содержать:

- `reasoning` — разбор аргументов каждой стороны
- `facts` — список проверяемых тезисов с пометкой "верно/неверно/непроверяемо"
- `sources` — какие источники/тип источников это подтверждают (Википедия, научная статья, закон, документация)
- `advice` — как закрыть спор без нового срача

Если источники не найдены — судья обязан это честно написать, а не выдумывать.

### 5. Прозрачность

- Опция `Прикладывать транскрипт` — к вердикту прикладывается анонимизированный транскрипт в `<blockquote expandable>`. Любой может проверить что судья видел именно то, что было в чате.
- В вердикте всегда: `Сообщений разобрано: N (запрошено M)` — видно если истории не хватило.
- Логи `adb logcat | grep "ИИ Суд"` + буллетени — всё что делает плагин прозрачно.

### 6. Невмешательство

- Команда `.суд` удаляется из чата (`HookStrategy.CANCEL` в `on_send_message_hook:182`) — не оставляет мусора
- Вердикт — **одно** сообщение реплаем на исходный спор, не спамит
- Стелс-мод — для теста вообще ничего не уходит в чат, только в Избранное

## 🎯 Команды

### Основной суд (по реальному срачу)

Отвечай **ответом (reply)** на сообщение, после которого начался срач:

```
.суд @user1 @user2 50
```

| Часть | Что значит |
|-------|------------|
| `.суд` | префикс, также `.court` `/суд` `!суд` `.judge` |
| `@user1 @user2` / `!user1 !user2` | участники спора (0-5). `@` тегает, `!` — без тега (не пингует). Если пусто — суд берёт все сообщения подряд |
| `50` | сколько сообщений **ПОСЛЕ** реплая разобрать (3-200, дефолт 50) |

**Примеры:**
```
.суд @alice @bob 50   → 50 сообщений только от alice и bob после реплая (с тегом)
.суд !alice !bob 50  → то же, но без тега/пинга
.суд 30               → 30 сообщений всех подряд после реплая
.суд @ivan 20         → 20 сообщений только от ivan
```

> Важно: всегда отправляй **ответом** на сообщение. Число — это окно **после** этого сообщения, а не последние сообщения чата.

### Тестовые команды (без реплая, без чата)

Для проверки что плагин вообще работает, не спамя чат:

| Команда | Что делает | Куда уходит ответ |
|---------|------------|-------------------|
| `.суд тест` / `.судтест` / `.court test` | Синтетический срач (6 сообщений про плоскую vs круглую Землю) → полный пайплайн анонимизации + LLM | В тот же чат (или в Избранное если стелс-мод) |
| `.суд пинг` / `.суд ping` / `.court ping` | Пинг LLM: шлёт `pong` и проверяет ключ/URL/модель | Туда же |

Также тесты доступны из **Настройки → Плагины → ИИ Судья → Тестирование** двумя кнопками:
- `🧪 Тестовый суд — фейковый срач` — то же что `.суд тест`, но всегда в Избранное
- `🔍 Проверить LLM (пинг)` — то же что `.суд пинг`

## 🔧 Как это работает технически

```
Ты: .суд @alice @bob 50 (reply #123)
        ↓ on_send_message_hook:102 перехватил, CANCEL, run_on_queue
        ↓ _fetch_history:317  TL_messages_getHistory(min_id=123, limit=50) + contacts.resolveUsername
        ↓ _anonymize:586      user 111 → Сторона A, user 222 → Сторона B, build transcript
        ↓ _call_llm:637       POST {base_url}/chat/completions  {system, user: transcript}
        ↓ _format_verdict:699 deanon Сторона A → @alice, render HTML
        ↓ _safe_send:779      send_text(peer, verdict) реплаем в чат (или в Избранное если стелс)
```

1. **Сбор** — `TL_messages_getHistory` с `min_id = reply_id` (только новее реплая), фильтрует по `wanted_ids` если указаны `@`
2. **Аноним** — детерминированная замена, порядок `A/B` зависит только от порядка появления в треде. **Нельзя отключить**
3. **Суд** — OpenAI-совместимый API, `temperature=0.2`, требует JSON
4. **Публикация** — HTML с `<b>`, `<blockquote expandable>`, `parse_mode="HTML"`

## 🛠️ Гайд по настройке (пошагово)

### Шаг 1. Где взять API ключ

Плагин совместим с любым OpenAI-совместимым API. Два быстрых варианта:

**Вариант A — OpenRouter (рекомендуется, есть бесплатные модели):**
1. Иди на https://openrouter.ai/keys → войди через Google/GitHub
2. Нажми `Create API Key` → скопируй `sk-or-v1-...`
3. Бесплатные модели: `deepseek/deepseek-chat:free`, `meta-llama/llama-3.1-8b-instruct:free`

**Вариант B — OpenAI:**
1. https://platform.openai.com/api-keys → Create new secret key
2. Скопируй `sk-proj-...` (потребуется баланс)

**Вариант C — локально (макс приватность):**
- Поставь Ollama + `openai-compatible` прокси, укажи `http://10.0.2.2:11434/v1` (с эмулятора)

### Шаг 2. Заполни настройки плагина

`Настройки → Плагины → ИИ Судья`:

| Поле | Что вписать | Пример |
|------|-------------|--------|
| `API ключ` | ключ из шага 1 | `sk-or-v1-xxxx` |
| `Base URL` | адрес API | `https://openrouter.ai/api/v1` или `https://api.openai.com/v1` |
| `Модель` | имя модели | `deepseek/deepseek-chat:free` / `gpt-4o-mini` |
| `Лимит по умолчанию` | 50 | оставь 50 |
| `Стелс-мод` | для теста включи | ON → вердикты в Избранное |

Нажми назад — настройки сохранятся.

**Если поля не видно / не редактируется** (баг некоторых сборок) — введи через чат:
```
.суд ключ sk-or-v1-xxxxx
.суд база https://openrouter.ai/api/v1
.суд модель deepseek/deepseek-chat:free
.суд статус   → покажет что сохранено (в Избранное)
```
Все команды удаляются после отправки, ответ приходит в Избранное (при стелс=ON) или буллетенем.

### Шаг 3. Проверь что LLM отвечает

Не надо сразу срать в чате. Проверь пинг:

1. В настройках плагина нажми `🔍 Проверить LLM (пинг)` — ответ должен прийти в **Избранное** за 2-5 сек: `✅ LLM OK (200)`
2. Или в любом чате напиши `.суд пинг` — то же самое

Если `❌ HTTP 401` → неверный ключ. `❌ HTTP 404` → неверный Base URL. `❌ HTTP 429` → кончился баланс/лимит.

### Шаг 4. Запусти тестовый суд

1. В настройках нажми `🧪 Тестовый суд — фейковый срач` — или в чате `.суд тест`
2. В Избранное (или чат) придёт 3 сообщения:
   - `🧪 Тестовый суд запущен`
   - `🔒 Анонимизация: OK` + транскрипт `Сторона A/B`
   - `🧪 ТЕСТОВЫЙ ВЕРДИКТ` — если LLM жив, увидишь кто прав про плоскую Землю (должен победить Сторона B)

Если 3 сообщения пришли и вердикт адекватен — плагин готов.

### Шаг 5. Первый реальный суд

1. Включи стелс-мод (чтобы не спамить пока тренируешься)
2. Найди срач, ответь на **первое** сообщение срача: `.суд @alice @bob 30`
3. Команда исчезнет, в Избранное придёт `🏛 Суд созывается…` → `🔍 Собрано N` → вердикт
4. Если всё ок — выключи стелс, следующий вердикт уйдёт в чат реплаем

## 🕵️ Стелс-мод

Включи в настройках `Стелс-мод (в Избранное)`:

- Вердикт **не уходит в чат**, а только в **Избранное (Saved Messages)**
- Команда `.суд` всё равно удаляется из чата — никто не видит что был суд
- В Избранном шапка: `🕵️ Стелс-мод: вердикт из чата -100123 #456 → только тебе`
- `Куда слать в стелсе` — можно вписать `@username` или `peer_id` чтобы слать не в Избранное, а другу/второму акку
- `🏛 Суд созывается…` тоже уходит только тебе

Выключил — снова обычный режим (вердикт реплаем в чат). Для теста фейковых команд стелс тоже работает.

## 📄 Формат вердикта

```
🏛 ИИ СУД — ВЕРДИКТ
⚖️ Судья не знал реальные ники — судил анонимно

👥 Сторона A → Alice | Сторона B → Bob
💬 Сообщений разобрано: 24 (запрошено 50) • реплай #123

🏆 Победитель: Сторона A (Alice) (уверенность 78%)

Кратко: Сторона A права — привела данные, у B — подмена тезиса

Разбор:
1. Alice: тезис X, источник Y — корректно
2. Bob: тезис Z — логическая ошибка ...

Факты:
• Alice: "Земля круглая" — верно
• Bob: "5G чипирует" — неверно

Источники:
• NASA, учебник физики

Совет: закройте спор ссылкой на ...

Макросы: {winner}=Сторона A (Alice), {count}=24
```

Все `Сторона X` уже раскрыты в `Сторона X (Имя)` — честно и читаемо.

## 🛡️ Что не может сломать честность

| Угроза | Защита |
|--------|--------|
| Админ/старожил давит авторитетом | Слепой суд — судья не видит ролей (нельзя отключить) |
| Друзья заступаются | Судит только текст, не соцграф |
| Громкость/капс | Анализируется логика, а не оформление |
| Подмена сообщений после суда | Берётся снапшот истории по `min_id`, транскрипт прикладывается |
| Модель галлюцинирует источники | Промпт требует `sources` и `facts`, при сомнениях — `Недостаточно данных` |
| Подглядел ник и подсудил | Невозможно — ник подменяется до LLM |
| Отключил аноним чтобы подсудить друзьям | Невозможно — переключатель убран |

## 🔐 Приватность

- `api_key` хранится только в `get_setting` на устройстве, никуда кроме твоего `base_url` не уходит
- Транскрипт уходит только в твой LLM-провайдер (OpenAI/OpenRouter/твой self-host)
- Хочешь максимум приватности — поставь `base_url` на свой локальный LLM (Ollama, vLLM) — плагин OpenAI-совместим

## 🧪 Диагностика если "чета не работает"

1. **SDK версия** → `Plugin requires sdk version >=1.4.5.0` — исправлено в v1.0.1: теперь `>=1.4.3.0`. Переустанови файл из репы.
2. **Не собирается история** → в Избранное придёт `❌ не удалось собрать сообщения`. Причины: после реплая нет новых сообщений, или нет прав на чтение. Попробуй `.суд тест` — если он работает, дело в истории, не в LLM.
3. **LLM не отвечает** → `.суд пинг` покажет HTTP код. 401=ключ, 404=URL, 429=баланс.
4. **Ничего не приходит** → Проверь логи `adb logcat | grep "ИИ Суд"` или включи стелс и смотри Избранное.
5. Сначала всегда гоняй `.суд тест` / `.суд пинг` — они не требуют реплая и показывают где именно падает.

## 💡 Идея

Срачи неизбежны. Но пусть их решает не тот кто громче, а тот кто прав. ИИ Судья — это попытка дать чатам инструмент **быстрого, прозрачного и абсолютно слепого** правосудия.

Если нашёл баг/идею — Issues / PR.

## 📎 Про расширения `.py` / `.plugin` / `.elyx`

- **На устройстве** exteraGram хранит однофайловые плагины как `/files/plugins/<id>.py` (`Setup`).
- **Для раздачи** однофайловый — тот же `.py` переименованный. В сторах `.plugin` (англ.) и `.plagin` (рус. транслит) — лоадер парсит `AST`, ему всё равно.
- **Elyx** — ZIP где в корне `refmap.yml` (`Project Structure`). Официально `.elyx` / `.eaf` (и `.elyx.zip`). Можно переименовать в `.plugin` — откроет.

В репо лежат все варианты, они идентичны по коду.
